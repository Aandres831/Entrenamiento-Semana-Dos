# 📊 Sistema de Calificaciones RIWI

¡Bienvenido al **Sistema de Calificaciones RIWI**! 🎓✨ Este proyecto te permite procesar y analizar las calificaciones finales de los estudiantes de un curso, determinando si han aprobado y proporcionando estadísticas útiles.

## 🚀 Características

- 📌 **Ingreso de calificaciones:** Los usuarios pueden introducir las calificaciones separadas por comas.
- 📊 **Validación de datos:** Se verifican que las calificaciones estén dentro del rango permitido (1-100).
- 📈 **Cálculo de promedio:** Se calcula la media de todas las notas ingresadas.
- ✅ **Clasificación de estudiantes:** Se informa si cada estudiante ha aprobado o reprobado.
- 🔍 **Comparación de notas:** Se permite ingresar una nota de referencia para analizar cuántas notas son mayores o iguales a ella.
- 🔁 **Iteración opcional:** El usuario decide si desea ingresar otra lista de calificaciones.
